# MAINQUEST 🚀

### Your career is the main quest.

MAINQUEST is a career-growth platform designed to help students turn passive learning into meaningful action.

Instead of asking:

> "What should I watch next?"

MAINQUEST asks:

> "What should I DO next?"

---

## 🎯 Problem

Students often consume large amounts of educational content but struggle to convert that learning into practical skills, projects and career progress.

MAINQUEST addresses this problem by turning career preparation into a personalized quest system.

---

## 💡 Solution

The user chooses a career goal such as:

- AI/ML Engineer
- Software Engineer
- Data Scientist
- Web Developer
- Cybersecurity
- UI/UX Designer

MAINQUEST then creates a personalized journey consisting of:

**LEARN → DO → TRACK → ADAPT → PROGRESS**

---

## ⭐ Key Features

### 🎯 Main Quest

A user's long-term career goal.

Example:

**AI/ML Engineer**

### 🗺️ Quest Map

A visual roadmap showing the skills and milestones required for the selected career.

### ⚔️ Side Quests

Small actionable tasks such as:

- Solve a DSA problem
- Complete a technical quiz
- Build a mini project
- Improve a GitHub repository
- Practice an interview question

### 🤖 Quest Coach

An AI career assistant designed to help users decide what to learn and work on next.

### 📊 Progress Tracking

Tracks:

- XP
- Level
- Streak
- Skill progress
- Completed activities
- Career progress

### 🧠 Personalized Recommendations

Recommendations are based on factors such as:

- Career goal
- Interests
- Current skill level
- Activity history
- Performance
- Skill gaps
- Activity preferences

### 🎮 Gamification

Users earn XP by completing meaningful activities.

| Activity | XP |
|---|---:|
| Learn | +1 |
| Quiz | +5 |
| Coding | +10 |
| Project | +25 |
| Real-world action | +30 |

---

## 🔄 Adaptive Learning

MAINQUEST adapts recommendations based on user behaviour.

For example:

**Repeated success**

→ gradually increase difficulty

**Repeated failure**

→ recommend prerequisite or easier activities

**Repeated skipping**

→ change activity type or reduce difficulty

This allows the system to focus on the user's next useful action.
